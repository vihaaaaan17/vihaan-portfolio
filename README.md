## ⚡ Local Development

To run the portfolio locally on your machine:

```powershell
# Navigate to the static portfolio directory
cd vihaan-portfolio-static

# Run local dev server using npx serve
cmd /c npx -y serve .
```

Open **`http://localhost:3000`** in your web browser.

---

## 🚢 Continuous Deployment (Vercel)

This repository is linked to Vercel for automatic continuous deployment.

1. **Make changes** to `index.html` or assets.
2. **Commit and push** to the `main` branch:
   ```powershell
   git add .
   git commit -m "Update portfolio content"
   git push
   ```
3. Vercel automatically builds and deploys your changes live within seconds!
